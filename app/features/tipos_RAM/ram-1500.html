¿Qué es la RAM 1500?

La RAM 1500 es la camioneta full-size que define a la marca en Norteamérica. A partir de este modelo el número ya no indica kilogramos de carga sino la categoría de servicio: la 1500 corresponde al servicio ligero dentro de las camionetas grandes.

Su rasgo distintivo frente a la competencia es la suspensión trasera con resortes helicoidales, que mejora la comodidad de marcha. Con el motor V8 HEMI alcanza una capacidad de remolque cercana a las seis toneladas.
